## 📌 About The Project

This repository hosts the official personal portfolio website for **Abdullah Bin Taleb**. Designed with modern UI/UX principles, seamless transitions, and interactive components to showcase selected academic work, live production web applications, and data analytics dashboards.

### ✨ Key Features

- 🌓 **Dynamic Day/Night Theme:** Interactive toggle switch between sleek Dark Mode and refined Light Mode with local storage persistence.
- 💻 **Animated Code Ticker:** Ambient background streaming authentic Python, C++, and R data science algorithms.
- ⚡ **Twitter-Style Live Previews:** Card components with real-time status badges and responsive preview displays.
- 📱 **Fully Responsive:** Fluid layout optimized across mobile, tablet, and desktop viewports.
- 📄 **Direct Resume Access:** Quick access to the latest PDF resume.
